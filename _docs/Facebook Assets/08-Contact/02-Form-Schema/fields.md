# CONTACT FORM FIELDS

| Code | VI | EN | Required | Notes |
|---|---|---|---:|---|
| `name` | Họ và tên | Full name | Yes | `autocomplete=name` |
| `company` | Công ty | Company | No | `autocomplete=organization` |
| `email` | Email | Email | Yes | Valid email |
| `phone` | Số điện thoại | Phone number | No | Normalize server-side |
| `serviceInterest` | Dịch vụ quan tâm | Service of interest | No | Stable service code |
| `message` | Nội dung yêu cầu | Tell us about your project | Yes | Lưu nguyên ngôn ngữ user nhập |
| `privacyConsent` | Đồng ý chính sách quyền riêng tư | I agree to the Privacy Policy | Yes | Versioned evidence |
| `website` | — | — | No | Honeypot, không hiển thị |
