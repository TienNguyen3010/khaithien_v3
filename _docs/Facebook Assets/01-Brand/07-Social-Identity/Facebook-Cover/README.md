# KHẢI THIÊN — FACEBOOK COVER

## Mục đích

Lưu trữ banner/cover từ fanpage làm nguồn tham khảo cho nhận diện và nội dung website V3. Banner social không được dùng trực tiếp làm hero website nếu chưa tái thiết kế responsive và xác minh thông tin.

## Cấu trúc

```text
Facebook-Cover/
├── Original/    # File ảnh gốc tải từ Facebook hoặc đơn vị thiết kế
├── Derived/     # Bản crop/resize đã được duyệt
├── References/  # File thiết kế, link, screenshot hoặc ghi chú liên quan
├── content-inventory.md
├── asset-manifest.json
└── README.md
```

## File ảnh đang chờ bổ sung

Ảnh được gửi trong cuộc trò chuyện chưa tồn tại dưới dạng file trong thư mục dự án. Hãy lưu ảnh vào:

```text
Original/khai-thien-facebook-cover-original.jpg
```

Ưu tiên file gốc từ Facebook/đơn vị thiết kế, không dùng screenshot nếu có bản chất lượng cao hơn.

## Trạng thái sử dụng

- Loại tài sản: Facebook cover/landing banner.
- Vai trò: tài liệu tham khảo nhận diện và nguồn discovery nội dung.
- Production website: **chưa duyệt**.
- Lý do: ảnh raster, nhiều text cố định, không responsive và thông tin liên hệ chưa được xác minh.

## Hướng tái sử dụng cho website

- Logo → header/footer sau khi có file vector.
- PR, Event, Production House, Activation → service cards.
- Ảnh sự kiện → project/case study khi có file gốc và quyền sử dụng.
- Website, điện thoại, địa chỉ → trang Contact sau khi Business Owner xác nhận.
- Không nhúng nguyên banner vào hero website.
