# APPROVED TESTIMONIALS

Thư mục hiện trống.

Mỗi testimonial approved cần:

- Testimonial ID.
- Quote VI/EN được duyệt.
- Source ID và approval evidence ID.
- Speaker public name/title hoặc quy tắc ẩn danh.
- Client/project mapping.
- Logo/portrait rights ID nếu hiển thị.
- Approval date và expiry/review date.
- Approved channels/locales.

Chỉ status `approved` và chưa hết hạn mới được query cho website public.
