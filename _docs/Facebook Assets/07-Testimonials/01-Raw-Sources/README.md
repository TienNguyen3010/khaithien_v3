# RAW TESTIMONIAL SOURCES

Lưu hoặc tham chiếu nguồn nguyên bản:

- Email cảm ơn/phản hồi của khách hàng.
- Survey sau dự án.
- Biên bản nghiệm thu có nhận xét.
- Transcript phỏng vấn.
- Tin nhắn chỉ khi có consent cho phép dùng công khai.
- Bài báo có quote rõ nguồn.

## Metadata bắt buộc

- Source ID.
- Client/project ID.
- Ngày nhận.
- Người nhận/owner nội bộ.
- Kênh nguồn.
- File hoặc evidence location.
- Có PII hay không.
- Consent status.

Không lưu screenshot chứa PII vào repository public.
