# SPEAKER MEDIA

- Portrait phải là file gốc hoặc file được cấp phép.
- Client logo tuân thủ `06-Clients/03-Logo-Assets` và logo approval.
- Không lấy avatar Facebook cá nhân làm portrait production nếu chưa có consent.
- Có thể hiển thị testimonial không portrait nếu quote vẫn đáng tin và được duyệt.
- Nếu client yêu cầu ẩn danh, không dùng ảnh, logo hoặc chi tiết có thể suy ra danh tính.

Metadata: media ID, owner, photographer, rights ID, crop, alt VI/EN, expiry và credit.
