# APPROVED CLIENTS

Thư mục hiện trống vì chưa có client được phê duyệt công bố.

Mỗi client approved cần:

- Client ID ổn định.
- Tên public VI/EN.
- Tên pháp lý nếu cần.
- Website chính thức.
- Ngành/taxonomy.
- Project IDs liên quan.
- Phạm vi cho phép: logo wall, case study, testimonial, social preview.
- Approval evidence ID, ngày duyệt và expiry.
- Logo master file và usage rules.

Không dùng candidate record làm approved client.
